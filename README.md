<picture><source media="(prefers-color-scheme: dark)" srcset="assets/hobelbank-dark.svg"><source media="(prefers-color-scheme: light)" srcset="assets/hobelbank-light.svg"><img src="assets/hobelbank-universal.svg" width="56" height="56" align="left" alt="Hobelbank logo"></picture> **[Hobelbank](https://pihme.github.io/hobelbank/)** is the umbrella over the projects below. They share one question: how do you build software in the age of AI? Each project takes on one part of the answer, from the world an agent works in to the guards on its way out.
<br clear="left">

- <img src="assets/fregoli.svg" width="18" height="18" alt=""> **[Fregoli](https://pihme.github.io/fregoli/)** · [repository](https://github.com/pihme/fregoli)  
  A web application an agent can rewrite while it is running: capabilities are Cordis plugins mounted and unmounted in a live Node process.
- <img src="assets/hermetarium.svg" width="18" height="18" alt=""> **[Hermetarium](https://pihme.github.io/hermetarium/)** · [repository](https://github.com/pihme/hermetarium)  
  The world an agent wakes up in: an OCI image it may use freely as root, behind a wall with Squid as the only, logged way out.
- <img src="assets/git-warden.svg" width="18" height="18" alt=""> **[Git Warden](https://pihme.github.io/git-warden/)** · [repository](https://github.com/pihme/git-warden)  
  Guard posts between AI agents and their Git remote: a Push Guard that checks every push with deterministic rules, and a Backup Guard that keeps an append-only backup of every branch and tag.
- <img src="assets/grok-budget-mcp.svg" width="18" height="18" alt=""> **[grok-budget-mcp](https://pihme.github.io/grok-budget-mcp/)** · [repository](https://github.com/pihme/grok-budget-mcp)  
  A small local MCP server that tells a Grok Build agent how much of its weekly usage pool is left, the same figure as /usage. Read-only, unofficial endpoint.
- <img src="assets/claude-budget-mcp.svg" width="18" height="18" alt=""> **[claude-budget-mcp](https://pihme.github.io/claude-budget-mcp/)** · [repository](https://github.com/pihme/claude-budget-mcp)  
  A small local MCP server that tells a Claude Code agent how much of its 5-hour and weekly usage limits is left, the same figures as /usage. Read-only, unofficial endpoint.
- <img src="assets/helferlein.svg" width="18" height="18" alt=""> **[Helferlein](https://pihme.github.io/helferlein/)** · [repository](https://github.com/pihme/helferlein)  
  An animated Three.js 3D avatar that a web page can summon: it floats in, shows when it is waiting or working, and gets a random new look on every applied change.

**My Tool Cabinet** holds software I pick, adapt or build for my own use, so I keep control over my data.

- <img src="assets/mdmtmr.svg" width="18" height="18" alt=""> **[My Data, My Tools, My Rules](https://pihme.github.io/my-data-my-tools-my-rules/)**  
  A catalogue of off-the-shelf options: a wiki-style directory of open-source projects for digital self-determination.
- <img src="assets/bespoke-freemind-ce.png" width="18" height="18" alt=""> **[bespoke-freemind-ce](https://github.com/pihme/bespoke-freemind-ce)**  
  A tailored build of FreeMind CE, the classic mind-mapping software.
- <picture><source media="(prefers-color-scheme: dark)" srcset="assets/ragite-dark.svg"><source media="(prefers-color-scheme: light)" srcset="assets/ragite-light.svg"><img src="assets/ragite-light.svg" width="18" height="18" alt=""></picture> **[RAGite](https://pihme.github.io/ragite/)** · [repository](https://github.com/pihme/ragite)  
  A building block for local RAG: embeddable, CPU-friendly retrieval as a SQLite extension.
- <img src="assets/ragite-demo.svg" width="18" height="18" alt=""> **[RAGite demo](https://pihme.github.io/ragite-demo/)** · [repository](https://github.com/pihme/ragite-demo)  
  Search the SQLite docs and Wikipedia in your browser with RAGite and Datasette, offline and in one SQLite file.
